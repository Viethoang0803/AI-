# Orbital Hands

Quả cầu hạt 3D (3000 hạt) điều khiển bằng cử chỉ tay qua webcam + MediaPipe Hands.

## Dùng trên điện thoại

Mở link GitHub Pages (HTTPS bắt buộc để dùng camera):

**https://viethoang0803.github.io/AI-/**

1. Nhấn **Bật camera** và cho phép quyền camera  
2. Đưa tay vào khung hình  
3. Chrome / Safari hiện đại khuyến nghị  

## Cử chỉ

| Cử chỉ | Hiệu ứng |
|--------|----------|
| Một tay | Di chuyển + xoay quả cầu |
| Chụm giữ rồi thả (khi đầy vòng) | Hạt phát nổ rồi tái tạo |
| Hai tay dang / chụm | Phóng to / thu nhỏ |
| Đếm ngón tay | Đổi màu hạt |
| Nút Webcam nền | Bật nền camera toàn màn hình |

## Chạy local

Mở `index.html` qua HTTPS hoặc localhost (camera không chạy trên `file://` ở nhiều trình duyệt).
